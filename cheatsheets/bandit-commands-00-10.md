# Bandit Level 0~10 핵심 명령어

| 단계            | 핵심 명령어                                                              | 기능                               |
| ------------- | ------------------------------------------------------------------- | -------------------------------- |
| Level 0 → 1   | `ls -la`                                                            | 숨김 파일을 포함한 파일 목록과 상세 정보 확인       |
| Level 0 → 1   | `cat readme`                                                        | `readme` 파일 내용 출력                |
| Level 1 → 2   | `cat ./-`                                                           | 이름이 `-`인 파일 읽기                   |
| Level 2 → 3   | `cat -- "--spaces in this filename--"`                              | `--`로 시작하고 공백이 포함된 파일 읽기         |
| Level 3 → 4   | `cd inhere`                                                         | `inhere` 디렉터리로 이동                |
| Level 3 → 4   | `ls -la`                                                            | 숨김 파일 확인                         |
| Level 3 → 4   | `cat ...Hiding-From-You`                                            | 숨김 파일 내용 출력                      |
| Level 4 → 5   | `file ./*`                                                          | 현재 디렉터리의 일반 파일 형식 확인             |
| Level 4 → 5   | `cat ./-file07`                                                     | `-`로 시작하는 텍스트 파일 읽기              |
| Level 5 → 6   | `find . -type f -size 1033c ! -executable`                          | 1033바이트이며 실행 불가능한 일반 파일 검색       |
| Level 5 → 6   | `file ./검색된/파일경로`                                                   | 검색된 파일의 형식 확인                    |
| Level 5 → 6   | `cat ./검색된/파일경로`                                                    | 검색된 파일 내용 출력                     |
| Level 6 → 7   | `find / -type f -user bandit7 -group bandit6 -size 33c 2>/dev/null` | 서버 전체에서 소유자·그룹·크기 조건으로 파일 검색     |
| Level 6 → 7   | `cat /검색된/파일경로`                                                     | 검색된 파일 내용 출력                     |
| Level 7 → 8   | `grep millionth data.txt`                                           | `millionth`가 포함된 줄 검색            |
| Level 8 → 9   | `sort data.txt \| uniq -u`                                          | 정렬 후 한 번만 등장하는 줄 출력              |
| Level 9 → 10  | `strings data.txt \| grep '==='`                                    | 바이너리에서 문자열을 추출하고 `===`가 포함된 줄 검색 |
| Level 10 → 11 | `base64 -d data.txt`                                                | Base64로 인코딩된 데이터 디코딩             |

## 주요 보조 명령어

| 명령어             | 기능                        |
| --------------- | ------------------------- |
| `pwd`           | 현재 작업 디렉터리 확인             |
| `ls`            | 현재 디렉터리의 일반 파일 목록 확인      |
| `ls -a`         | 숨김 파일을 포함한 목록 확인          |
| `ls -la`        | 숨김 파일을 포함한 상세 목록 확인       |
| `cd 디렉터리명`      | 지정한 디렉터리로 이동              |
| `cd ..`         | 상위 디렉터리로 이동               |
| `cat 파일명`       | 파일 내용 출력                  |
| `cat -A 파일명`    | 공백, 탭, 줄 끝 등 보이지 않는 문자 확인 |
| `file 파일명`      | 파일 형식 판별                  |
| `find 시작경로 조건`  | 조건에 맞는 파일과 디렉터리 검색        |
| `grep 문자열 파일명`  | 특정 문자열이 포함된 줄 검색          |
| `sort 파일명`      | 파일 내용을 줄 단위로 정렬           |
| `uniq -u`       | 한 번만 등장하는 줄 출력            |
| `uniq -c`       | 각 줄의 등장 횟수 출력             |
| `strings 파일명`   | 바이너리 파일에서 읽을 수 있는 문자열 추출  |
| `base64 -d 파일명` | Base64 데이터 디코딩            |
| `reset`         | 바이너리 출력 등으로 깨진 터미널 초기화    |
| `exit`          | 현재 SSH 접속 종료              |

## 주요 기호 및 옵션

| 기호·옵션           | 의미                        |
| --------------- | ------------------------- |
| `.`             | 현재 디렉터리                   |
| `..`            | 상위 디렉터리                   |
| `./파일명`         | 현재 디렉터리의 파일을 경로로 지정       |
| `*`             | 숨김 파일을 제외한 모든 파일명         |
| `--`            | 명령어 옵션 입력 종료              |
| `"파일 이름"`       | 공백이 포함된 문자열을 하나의 인자로 처리   |
| `\`             | 공백이나 특수문자를 이스케이프          |
| `\|`            | 앞 명령어의 출력을 뒤 명령어의 입력으로 전달 |
| `>`             | 명령어 결과를 파일에 덮어쓰기          |
| `>>`            | 명령어 결과를 파일 끝에 추가          |
| `2>/dev/null`   | 오류 출력을 버림                 |
| `-type f`       | 일반 파일만 검색                 |
| `-size 1033c`   | 정확히 1033바이트인 파일 검색        |
| `-user 사용자명`    | 특정 사용자가 소유한 파일 검색         |
| `-group 그룹명`    | 특정 그룹이 소유한 파일 검색          |
| `! -executable` | 실행 가능한 파일 제외              |
| `-u`            | 한 번만 등장한 줄 출력             |
| `-c`            | 줄별 등장 횟수 출력               |
| `-d`            | 중복된 줄만 출력                 |
