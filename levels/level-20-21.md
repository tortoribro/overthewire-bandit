# Bandit Level 20

## 1. 목표
- 홈디렉터리에 있는 suconnect라는 SUID 프로그램을 이용해서 
localhost의 특정 포트에 접속하고 현재 비밀번호를 보내고 다음 비밀번호를 받는다.

## 2. 문제 분석
- 현재 비밀번호를 확인한다.
- nc 포트를 열고 현재 비밀번호를 입력해서 포트에 접속한다. 포트번호는 임의로 설정해도되지만 0~9999범위내에 있어야하고 사용하지 않는 포트여야한다.
- 하나의 터미널을 더 만들고 bandit20으로 접속
- succonenct의 파일을 확인하여 실행법을 확인한다.
- succonnect로 설정한 포트에 접속하여 다음레벨의 비밀번호를 반환받는다.

## 3. 사용 명령어
- nc
- ./succonect <포트번호>


## 4. 명령어 분석
- nc -l -p 12345

| 구성      | 의미                        |
| ------- | ------------------------- |
| `nc`    | Netcat 실행                 |
| `-l`    | listen 모드, 연결을 기다리는 서버 역할 |
| `-p`    | 사용할 로컬 포트 지정              |
| `12345` | 대기할 포트 번호 (임의지정)                |


- 파이프를 사용
```bash
cat /etc/bandit_pass/bandit20 | nc -l -p 12345
```
