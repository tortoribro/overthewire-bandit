# Bandit Level 12

## 1. 목표
- 원본 파일을 16진수 형태로 출력한 헥스 덤프파일에서 원본파일을 추출후 압축을 해제하고 비밀번호를 얻어야한다.

## 2. 문제 분석
- 홈 디렉터리는 생성,수정 권한이 제한되므로 /tmp 아래에 임시 디렉터리를 생성후 데이터를 복사하여 분석한다.
- 핵스 덤프 확인
    - 원본 바이너리 파일 복원
    - 파일 형식 확인
    - 압축 해제
    - 다시 파일 형식 확인
    - 일반 텍스트가 나올 때까지 반복
- 복원된 파일의 실제 형식을 확인한다.
    - 확장자만 보고 압축형식을 추측하면 안된다.
    - file 파일명 명령어를 이용해 파일 형식을 확인해야한다.
- 파일의 형식에따라 확장자를 변경후 압축을 해제해야한다.

파일 형식 예
```
gzip compressed data
bzip2 compressed data POSIX 
tar archive
ASCII text
```

 텍스트형식의 파일이 나올때까지 다음 과정을 반복해야한다.

```
gzip인 경우
mv 현재파일 현재파일.gz
gzip -d 현재파일.gz

bzip2인 경우
mv 현재파일 현재파일.bz2
bzip2 -d 현재파일.bz2

tar인 경우
mv 현재파일 현재파일.tar
tar -xf 현재파일.tar

```

## 3. 사용 명령어
- 파일복사
```bash
cp ~/data.txt .
```
- 파일 형식확인
```bash
file 파일명
```
- 임시 디렉터리 생성
```bash
mktemp -d
```
 출력예시
``` bash
/tmp/tmp.ABC123xyz
```
- 명령어 변수 저장
```bash
workdir=$(mktemp -d) # 명령어 변수저장
cd workdir # 디렉토리로 이동
```
- 헥스 덤프를 바이너리로 복원
```bash
xxd -r data.txt > data.bin
```
- 파일의 확장자 변경
```bash
mv 현재파일 현재파일.확장자
```
- gzip 파일을 압축 해제

```bash
gzip -d data.gz
```
- bzip 파일을 압축해제
```bash
bzip2 -d data.bz2
```
- 타르 아카이브 해제
```bash
tar -xf data.tar
```

## 4. 명령어 분석
- cp ~/data.txt .

|구성요소|의미|
|-------|------|
|~|홈디렉터리
|.|현재디렉터리

- mktemp -d

|구성 요소|	의미|
|-------|------|
|mktemp	|고유한 이름의 임시 파일이나 디렉터리를 생성
|-d	|임시 파일이 아니라 임시 디렉터리를 생성
|   |생성된 디렉터리는 실행할 때마다 달라진다.
- workdir=$(mktemp -d)

|구성 요소|	의미|
|-------|------|
|$(...)| 괄호 안의 명령어를 실행한 결과를 가져오는 명령어 치환이다.
||따라서 mktemp -d로 만들어진 디렉터리 경로가 workdir 변수에 저장된다.

- gzip

|구성 요소|	의미|
|-------|------|
|gzip	|gzip 압축 프로그램
|-d	|압축 해제
|data.gz|압축을 해제할 파일

- bzip2

|구성 요소|	의미|
|-------|------|
|bzip2 |bzip2 압축 프로그램
|-d|압축 해제
|data.bz2| 압축을 해제할 파일
- tar

|구성 요소|	의미|
|-------|------|
|tar|여러 파일을 하나의 아카이브로 묶거나 해제
|-x|extract, 아카이브에서 파일 추출
|-f|사용할 아카이브 파일 지정
|data.tar|해제할 tar 아카이브
