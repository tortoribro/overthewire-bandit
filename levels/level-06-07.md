# Bandit Level 6

## 1. 목표
- 서버 전체에서 다음 조건을 만족하는 파일을 찾는다
```bash
소유자: bandit7
소유 그룹: bandit6
파일 크기: 33바이트
```

## 2. 문제 분석
- 서버 전체에서 만족하는 조건의 파일을 찾아야한다.
- find 명령어를 사용하여 서버에있는 모든 파일을 검색
- 서버 전체를 검색하면 대량의 오류가 나온다.
- 오류 메세지를 숨기고 원하는 파일만 출력되게 한다.

## 3. 사용 명령어

```bash
find / -type f -user bandit7 -group bandit6 -size 33c 2>/dev/null
```

## 4. 명령어 분석
| 부분               | 의미                 |
| ---------------- | ------------------ |
| `find /`         | 루트 디렉터리부터 서버 전체 검색 |
| `-type f`        | 일반 파일              |
| `-user bandit7`  | 소유자가 `bandit7`     |
| `-group bandit6` | 그룹이 `bandit6`      |
| `-size 33c`      | 정확히 33바이트          |
| `2>/dev/null`    | 오류 출력을 버림   (오류 출력 2번을 /dev/null로 보낸다.)      |

``` 
>/dev/null: 정상 출력 버림
2>&1: 오류 출력을 정상 출력과 같은 곳으로 보냄
```
---

#### 리눅스 표준 입출력 번호
| 번호  | 이름     | 의미    |
| --- | ------ | ----- |
| `0` | stdin  | 표준 입력 |
| `1` | stdout | 정상 출력 |
| `2` | stderr | 오류 출력 |
