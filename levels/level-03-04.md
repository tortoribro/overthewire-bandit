# Bandit Level 3

## 1. 목표
- inhere 디렉터리 안에 있는 숨김파일을 찾는다.

## 2. 문제 분석
- 리눅스에서는 파일 이름이 .로 시작하면 숨김 파일로 처리한다.
```
file.txt 일반파일
.file.txt 숨김파일
...secret 숨김파일
```
- ls 명령어로는 숨김파일이 보이지 않는다.

## 3. 사용 명령어
숨김 파일까지 보려면
```bash
ls -a
```
자세한 정보까지 보려면
```bash
ls -la
```

## 4. 명령어 분석
- ls -la 실행시 다음 항목이 보인다.
    - . : 현재디렉터리
    - .. : 상위디렉터리
- 현재 디렉터리에서 숨김 파일만 찾으려면
```bash
find . -maxdepth 1 -type f -name '.*'
```
| 옵션            | 의미              |
| ------------- | --------------- |
| `-maxdepth 1` | 현재 디렉터리까지만 검색   |
| `-type f`     | 일반 파일만 검색       |
| `-name '.*'`  | 이름이 점으로 시작하는 파일 |
