# Bandit Level 11

## 1. 목표
- data.txt 파일에 ROT13방식으로 변환된 문자열을 원래 문자열로 복원

## 2. 문제 분석
- ROT13은 모든 영문 대문자와 소문자는 알파벳 기준으로 13칸씩 이동된 상태이다.
- 원래 문자열로 복원하여 다음단계의 비밀번호를 알아낸다.

변환된 예시

알파벳을 13칸 이동
```bash
A B C ... M N O ... Z
↓
N O P ... Z A B ... M
```

## 3. 사용 명령어
```bash
tr 'A-Za-z' 'N-ZA-Mn-za-m' < data.txt
```
 - tr은 translate, 즉 문자 변환 명령어이다.

## 4. 명령어 분석

| 부분               | 의미                     |
| ---------------- | ---------------------- |
| `tr`             | 입력된 문자를 다른 문자로 변환      |
| `'A-Za-z'`       | 변환할 원본 문자 범위           |
| `'N-ZA-Mn-za-m'` | 변환 결과가 될 문자 범위         |
| `< data.txt`     | `data.txt`를 표준 입력으로 전달 |


```bash
'A-Za-z' : 대문자 A-Z ,소문자 a-z 까지
'N-ZA-Mn-za-m' : 대문자 N부터 M, 소문자 n부터 m까지
```
