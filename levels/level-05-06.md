# Bandit Level 5

## 1. 목표
- inhere 아래의 수많은 파일 중 다음 조건을 모두 만족하는 파일을 찾는다.
```
사람이 읽을 수 있음
크기가 정확히 1033바이트
실행 파일이 아님
```
## 2. 문제 분석
- 조건을 만족하는 파일을 찾아야한다.


## 3. 사용 명령어
```bash
find . -type f -size 1033c ! -executable
```
결과
```
file ./maybehere07/.file2
```

## 4. 명령어 분석
| 부분              | 의미            |
| --------------- | ------------- |
| `find`          | 파일과 디렉터리 검색   |
| `.`             | 현재 디렉터리부터 검색  |
| `-type f`       | 일반 파일만 검색     |
| `-size 1033c`   | 정확히 1033바이트   |
| `!`             | 조건 부정         |
| `-executable`   | 실행 가능한 파일     |
| `! -executable` | 실행 가능하지 않은 파일 |
