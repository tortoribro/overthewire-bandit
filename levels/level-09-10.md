# Bandit Level 9

## 1. 목표
- data.txt는 바이너리 데이터이며, 그 안에서 사람이 읽을 수 있는 문자열을 찾아야 한다. 비밀번호 근처에는 = 문자가 여러 개 있다.

## 2. 문제 분석
- 바이너리 데이터 안에서 사람이 읽을수 있는 데이터를 추출해야한다.
- '==='가 포함된 줄에 읽을 수 있는 데이터가 포함되어있으므로 파일에서 '==='을 찾아야한다.
- '===' =개수를 조정하여 범위를 좁힐 수 있다.

## 3. 사용 명령어
```bash
strings data.txt | grep '==='
```
- 바이너리 데이터에서 특정 문자열 추출

## 4. 명령어 분석
#### strings
- 바이너리 파일에서 출력 가능한 문자들이 일정 길이 이상 연속된 부분을 찾아 출력한다.
