# Bandit Level 8

## 1. 목표
- data.txt에서 다른 줄은 여러 번 등장하고, 딱 한 줄만 한 번 등장한다. 그 유일한 줄을 찾아야 한다

## 2. 문제 분석
- sort를 이용해서 정렬
- uniq -u 을 이용해 유일한 줄을 찾아야한다.
- uniq는 서로 연속해서 붙어있는 동일한 줄만 비교하므로 정렬해서 같은문자들을 붙여놓아야한다.
- uniq는 동일한 문자라도 떨어져있으면 같은문자로 인식못한다.



## 3. 사용 명령어
```bash
sort data.txt | uniq -u
```


## 4. 명령어 분석


정렬
```bash
sort data.txt
```

uniq
```bash
uniq -u
```
 - 서로 연속해서 붙어 있는 동일한 줄만 비교한다.
 - uniq는 동일한 문자라도 떨어져있으면 같은문자로 인식못한다.
   - -u :한 번만 등장한줄
   - -d :중복된 줄만 출력
   - -c :등장 횟수 표시

 ```bash
 명령어1 | 명령어2
 ```
