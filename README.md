# OverTheWire Bandit Write-up

OverTheWire Bandit 실습을 통해 학습한 Linux 명령어와
보안 기초 개념을 기록한 저장소입니다.

## 학습 목표 
- Linux 파일 및 디렉터리 구조 이해
- 특수한 파일명과 숨김 파일 처리
- find를 이용한 조건 기반 파일 탐색
- grep, sort, uniq를 이용한 텍스트 분석
- strings를 이용한 바이너리 문자열 추출
- Base64 인코딩과 디코딩 이해
- 표준 출력, 오류 출력 및 파이프 이해
